# Business Landing Page - Figma to HTML

Responsive, pixel-perfect landing page converted from Figma design to semantic HTML, CSS Flexbox/Grid.

## Features
- Semantic HTML5 (header, nav, main, section, article, footer)
- Flexbox for navbar and hero, CSS Grid for features
- Fully responsive (mobile first, media query @768px)
- Performance optimized: responsive images, minified CSS
- Accessible: alt text, ARIA labels, keyboard navigation
- Cross-browser tested: Chrome, Safari, Firefox

## Tech Stack
HTML5, CSS3, Flexbox, Grid, JavaScript

## How I built it
1. Analyzed Figma: colors, fonts, spacing
2. Built semantic HTML structure
3. CSS reset + desktop layout with Flexbox/Grid
4. Responsive with relative units and media queries
5. Tested cross-browser + compressed images
